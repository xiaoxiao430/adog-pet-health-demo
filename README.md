# 爱多格宠物健康管家 Demo

这是爱多格宠物医院与宠物店的用户端 P0/P1 共创原型，定位为可点击的业务样机。当前版本使用示例宠物、服务、时间和订单数据，不接真实支付、病历、预约接口或 AI API。

## 本地运行

```bash
npm install
npm run dev
```

打开 <http://localhost:3000/>。首次进入会看到爱多格品牌欢迎页，点击“进入爱多格”进入首页。

## 页面路径

- **首页**：切换阿布/汤圆、查看健康摘要、进入宠物档案、预约医疗/洗护、逛商城、打开在线咨询。
- **预约**：从底部“预约”进入；预约页左上角返回首页，确认后可修改、取消或回到首页。
- **宠物档案**：从底部“宠物档案”或首页档案入口进入；档案页右上角“编辑”可修改资料，页面底部导航可回首页。
- **添加宠物**：首页顶部宠物头像旁的“＋”进入独立表单，保存后自动建立档案并进入新宠物档案。
- **商城**：从底部“商城”或首页“逛逛商城”进入；底部“首页”返回首页。
- **我的**：从底部“我的”进入，查看预约、卡包、消费记录和家庭成员；底部“首页”返回首页。
- **在线咨询**：点击首页健康助手卡片、右上消息按钮或“我的”页健康助手卡片打开；右上角关闭按钮或点击遮罩关闭。

底部导航固定为“首页 / 预约 / 宠物档案 / 商城 / 我的”，当前页面会使用蓝色高亮，并提供对应的语义标签。

## 视觉与品牌

使用爱多格正式 Logo、蓝色与粉色暖色体系、Microsoft YaHei 中文字体。欢迎页使用透明 Logo、柔和光晕和渐入/淡出动画；首页保留宠物虚拟头像、全生命周期档案、预约服务、商城和健康助手的演示路径。

## 资料与照片

首页“＋”添加宠物，或在档案卡片点击“编辑”。可上传、更换和移除头像，修改名字、品种、性别、生日、体重、绝育、芯片、过敏和用药信息。照片支持 JPG/PNG/WebP，最大 8 MB，居中裁切压缩到 512px 后保存在浏览器本机。

保存后首页、档案、预约和助手会使用同一宠物资料；刷新保留资料与选择。取消编辑需确认放弃，已有医疗记录不会被资料编辑覆盖。新宠物不继承示例宠物的时间线和体检得分；体重或品种变化后显示“待评估”。数据暂不跨浏览器、域名或设备同步，清理浏览器数据会移除本机档案。

## 字号

主界面参照厚外成长已确认家长端：页面标题 24px、分区标题 20px、服务标题 15px、正文 13–14px、说明与导航 12px；表单输入 16px。进场动画字号保持原样，副文案为“一宠一档 记录成长”。
